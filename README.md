# Cricket Team Hub 🏏

A modern, responsive cricket team management web application inspired by Spond. Built with pure HTML5, Tailwind CSS, and vanilla JavaScript.

## Features
- **Squad Roster Management**: Add players, roles, batting hand, and bowling types.
- **Fixture RSVPs**: Attendance tracking (Attending, Tentative, Declined).
- **Match Day Playing XI Builder**: Filter by confirmed RSVPs, set batting order, and designate Captain (C) and Wicketkeeper (WK).
- **Match Reports & Summary**: Record scores, results, and award Player of the Match (POTM).
- **Match Dues Ledger**: Track match fees, payment statuses, and team finances.
- **Team Match Room & Polls**: In-app chat stream and voting polls for match logistics.
- **Mobile Ready**: Installable as a Progressive Web App (PWA) on iOS and Android.
